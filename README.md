# 8x8x8-True-Volumetric-display


A web-based BLE (Bluetooth Low Energy) interface for controlling an 8x8x8 LED cube using an HM-10 BLE module.


🌐 Live Demo

Access your app here:  ( https://faizulahasun-cloud.github.io/8x8x8-True-Volumetric-display/ )


Features


Bluetooth Connectivity: Pair with HM-10 BLE module

Auto/Manual Modes: Switch between automatic and manual control

Custom Functions: Upload user-defined 3D voxel functions to the LED cube

Real-time Status: Visual feedback on connection state



How to Use
Open the link above in a Bluetooth-enabled browser (Chrome, Edge, or Safari on supported devices)
Click "Pair HM-10 BLE Module" to connect to your LED cube
Use the control buttons to send commands:
details on user manual
